# Del Canvas a los números

Herramienta web para la fase financiera del Business Model Canvas en las hackathons Dream Big Challenge.

A partir de las 7 casillas superiores del Canvas, la app:

1. Propone ingresos y gastos que el equipo mantiene, descarta o añade.
2. Pide cuantificarlos (precio, unidades, crecimiento; gastos iniciales, fijos o variables) y la previsión de crecimiento de ingresos para los años 2 y 3.
3. Calcula la necesidad de inversión (inversión inicial + pérdidas de arranque + colchón de seguridad).
4. Propone vías de financiación con capital propio o ajeno (ENISA, ICO, microcréditos…) que el equipo valida.
5. Muestra el estado de flujos de caja a 3 años y un resumen para copiar.

Es un único `index.html` estático, sin dependencias. Los datos se guardan solo en el navegador de cada usuario.

Publicado con GitHub Pages: https://ief-bfs.github.io/canvas-financer/
